MODULE BREAKDOWN
1. REALTIME CORE (RUST)
Purpose

Everything latency-sensitive.

Responsibilities
wake word
VAD
audio streaming
interrupts
event queue
realtime scheduling
state synchronization
Why Rust
Python struggles with high-frequency realtime pipelines.

Rust gives:

deterministic performance
memory safety
async concurrency
near-C speed
2. EVENT BUS (VERY IMPORTANT)
Purpose

All modules communicate through events.

Example
USER_STARTED_SPEAKING
WINDOW_CHANGED
MUSIC_STARTED
WORKFLOW_TRIGGERED
Recommended
Tokio channels
ZeroMQ
NATS
Redis pub/sub

BEST IMPLEMENTATION STRATEGY
STEP 1 — Embedding Engine

Use:

MiniLM
BGE-small

Recommended:

all-MiniLM-L6-v2

Why?

lightweight
fast
excellent semantic similarity
CPU friendly
Suggested Structure
python-core/semantics/
 ├── embeddings.py
 ├── matcher.py
 ├── mapper.py
 ├── intent_registry.py
 └── semantic_memory.py
STEP 2 — Intent Registry

VERY IMPORTANT.

Define canonical workflow intents.

Example:

{
  "coding_mode": [
    "start coding",
    "open development setup",
    "prepare workspace",
    "i want to code"
  ],
  "focus_mode": [
    "too distracted",
    "need focus",
    "help me concentrate"
  ]
}
STEP 3 — Semantic Similarity Matching

Flow:

user utterance
    ↓
embedding vector
    ↓
cosine similarity
    ↓
nearest workflow intent

This is the core intelligence layer.

STEP 4 — Contextual Meaning Mapper

THIS is where Friday becomes smart.

Example:

User says:

“Pause this.”

Without context:

ambiguous

With context:

active YouTube tab
Spotify playing

Meaning becomes obvious.

THIS LAYER SHOULD ACCESS
current app
browser tab
media state
active workflow
workspace state
previous intent

This is EXTREMELY important.

IMPORTANT INSIGHT

Semantic intelligence becomes powerful ONLY when combined with:

context awareness

Without context:

embeddings alone are limited.
STEP 5 — Intent Confidence Thresholds

CRITICAL.

Do NOT always execute.

Example:

similarity > 0.85 → auto execute
0.65–0.85 → ask confirmation
<0.65 → fallback handling

This massively improves reliability.

STEP 6 — Adaptive Semantic Learning

Over time:

store new phrases
learn user vocabulary
expand intent clusters

Example:

You repeatedly say:

“lock in mode”

Eventually Friday learns:

“focus_mode”

This is how personalization emerges.

IMPORTANT ENGINEERING ADVICE

DO NOT use:

giant intent trees
endless regex
huge keyword maps

Use:

embeddings
similarity clusters
semantic memory

This scales MUCH better.
